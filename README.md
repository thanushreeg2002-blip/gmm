 # Rock Paper Scissors Game 🎮

## 📌 Project Overview

This project is a simple **Rock Paper Scissors game** built using Python.
The game allows a user to play against the computer. The computer randomly selects Rock, Paper, or Scissors, and the program determines the winner based on standard game rules.

This project is useful for beginners to understand:

* Python basics
* Conditional statements
* Random module
* User input handling
* Simple game logic

---

## 🕹️ Game Rules

1. Rock beats Scissors
2. Scissors beats Paper
3. Paper beats Rock
4. If both the user and computer choose the same option, the result is a **Draw**
